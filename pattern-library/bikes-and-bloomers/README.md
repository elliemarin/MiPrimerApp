# Bikes & Bloomers — copias originales con licencia

Nueve PDF descargados del proyecto [Bikes & Bloomers](https://bikesandbloomers.com/patterns/), dirigido por **Kat Jungnickel**, Goldsmiths, University of London. El proyecto acredita a Rachel Pimm, Nadia Constantinou, Alice Angus y Britt Hatzius; las portadas acreditan la fotografía de Charlotte Barnes. Los créditos completos, imágenes y avisos originales se conservan dentro de cada PDF.

**Licencia de los nueve PDF: [Creative Commons Atribución–NoComercial–CompartirIgual 4.0 Internacional](https://creativecommons.org/licenses/by-nc-sa/4.0/).** [Texto legal](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode).

La [página oficial de patrones](https://bikesandbloomers.com/patterns/) autoriza compartir, copiar, redistribuir y adaptar los diseños con atribución, uso no comercial y la misma licencia para adaptaciones. Esta es una copia gratuita para consulta. No se ha modificado ningún PDF; no se atribuyen sus diseños a Hilvana ni se implica respaldo del proyecto original. La licencia de esta carpeta no cambia la licencia del código de Hilvana ni se extiende a otros autores del catálogo.

`manifest.json` conserva la URL de la ficha, descarga oficial, licencia, fecha, tamaño, páginas y SHA-256 de cada archivo. Las dos variantes de bombacho y las tres prendas del conjunto son construcciones con PDF propios; no son tallas contadas como diseños diferentes.
