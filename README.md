# Hilvana

Aplicación web en español para diseño de prendas, patronaje personalizado,
intervención textil y gestión de proyectos de confección. Pensada primero para
iPhone y adaptable a tablet y computadora.

[Abrir Hilvana](https://elliemarin.github.io/MiPrimerApp/)

La biblioteca reúne 246 estilos con patrón editable; las tallas se eligen dentro
de cada diseño. El recorrido permite añadir extras, elegir telas y bordados, y
exportar las piezas con medidas e instrucciones. «Transformar mi ropa» ofrece
27 propuestas para modificar prendas existentes y obtener sus piezas adicionales.

Los patrones nuevos son experimentales: la validación geométrica debe completarse
con muestras impresas y cosidas. Las imágenes del catálogo son ilustrativas.
